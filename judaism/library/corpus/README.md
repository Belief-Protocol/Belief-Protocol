# Corpus

The tradition's own texts. Add the editions you work from here, with locators, so an agent can cite a page rather than paraphrase.

- The Tanakh, in Hebrew and in the translation the reader uses.
- The Mishnah and the Babylonian and Jerusalem Talmuds (Sefaria.org provides texts and translations).
- Maimonides, *Mishneh Torah*.
- The siddur and machzor of the reader's community.
