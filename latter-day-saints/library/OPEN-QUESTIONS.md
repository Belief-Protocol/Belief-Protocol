# Open questions: latter-day-saints

What this file is not sure of, and what only a competent authority in the tradition can settle.

## Review order

For each passage take one disposition: recognizable · wrong · missing · too strong · not theirs.

1. **The worldview headings.** Whether `Families can be together forever` belongs under Ultimate reality, or is better placed in the web.
2. **Grips.** Whether the Word of Wisdom should be `clenched`, since temple attendance requires it.
3. **The four anomalies.** Confirm each is genuinely unsettled.
4. **The dissonance entries.** Confirm the wording matches the Church's own acknowledgments.
5. **Christian identity.** How the file should state that the Church considers itself Christian while many other Christians do not.
