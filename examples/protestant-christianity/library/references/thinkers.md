# Thinkers

The teachers this file cites, and only those.

- **Martin Luther** (1483-1546) — justification by faith; the priesthood of all believers.
- **John Calvin** (1509-1564) — the sovereignty of God; Scripture and the Spirit.
- **Thomas Cranmer** (1489-1556) — the Book of Common Prayer; the Articles.
- **John Wesley** (1703-1791) — conversion, holiness, and the warmed heart.
- **Karl Barth** (1886-1968) — the Barmen Declaration.
