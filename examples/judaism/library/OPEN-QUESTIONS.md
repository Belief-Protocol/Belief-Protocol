# Open questions: judaism

What this file is not sure of, and what only a competent authority in the tradition can settle.

## Review order

For each passage take one disposition: recognizable · wrong · missing · too strong · not theirs.

1. **The principal.** Whether one file can stand for Judaism, or should be a base that stream-specific files extend.
2. **The framing paragraph** that Judaism is a covenant and a way of life more than a creed: recognizable to all streams?
3. **Grips.** Whether `Mitzvot and halakhah` should be `clenched`, as Orthodox Judaism would hold.
4. **The six anomalies.** Confirm each is fairly stated, in particular Zionism and the State of Israel.
5. **Mishnah Avot 2:16.** Numbered 2:21 in some editions; choose one and note the other.
6. **Mishnah Sanhedrin 4:5.** Manuscripts differ on "a single life" and "a single life of Israel"; say which is quoted.
